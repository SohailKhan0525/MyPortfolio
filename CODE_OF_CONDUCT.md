# Code of Conduct

## Our standard

We want this repository to remain a respectful, constructive space for learning and collaboration.

Expected behavior includes:

- being respectful and professional;
- giving feedback about the work rather than the person;
- welcoming different experience levels and perspectives;
- accepting corrections and changing course when evidence supports it;
- keeping discussions focused on improving the project.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, deliberate disruption, sexualized conduct, and publishing private information without permission.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, or restrict participation when behavior violates this standard.

For sensitive concerns, contact the maintainer privately rather than starting a public discussion.

This code of conduct is adapted from the principles of the Contributor Covenant.
